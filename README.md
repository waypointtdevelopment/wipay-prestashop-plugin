# Waypoint WiPay for PrestaShop

An independent PrestaShop payment integration project maintained by Waypoint. It is not affiliated with, sponsored by, or endorsed by WiPay.

## Project status

**Research only.** No current Waypoint-supported PrestaShop plugin or verified WiPay package is available in this repository. Supported PrestaShop/PHP versions and sandbox behavior remain to be confirmed.

## Direction

The intended integration would redirect shoppers to WiPay's hosted checkout and verify responses server-side. The store should not collect card details.
